# Urban Mobility & Bike Demand Analysis

## Project Overview
An exploratory data analysis project investigating bike-sharing demand patterns using hourly rental data from Washington, D.C.

## Objectives
- Analyze hourly, daily, and seasonal rental trends.
- Compare casual and registered rider behavior.
- Explore associations between weather conditions and bike demand.
- Develop evidence-based operational recommendations.

## Dataset
UCI Bike Sharing Dataset — hourly rental records from 2011–2012.

## Technologies
- Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Dataset inspection and data quality checks
2. Data cleaning and feature engineering
3. Exploratory data analysis
4. Visualization and interpretation
5. Business insights and recommendations

## Key Findings
- [Peak Rental Hours: Demand peaks at 5 PM (~461 rentals/hour), followed by 6 PM (~426) and 8 AM (~359).]
- [Seasonal Demand: Fall has the highest average demand (~236 rentals/hour), while spring has the lowest (~111).]
- [Weather and Demand: Clear weather has the highest average demand (~205 rentals/hour), while heavy adverse weather has the lowest (~74).]
- [Rider Types: Registered riders average ~154 rentals/hour versus ~36 for casual riders, accounting for around 81% of rentals.]

## Business Recommendations
[Optimize bike availability during peak hours, plan for seasonal demand, use weather forecasts for operational planning, and strengthen registered-rider retention while attracting casual riders.]
